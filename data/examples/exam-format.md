# Alberta Social Studies Diploma Exam — Formatting Guide

This document describes the conventions for Alberta Social Studies 30-1 diploma exam questions. Use this as the formatting template for all generated question sets.

---

## Part A: Multiple Choice Questions

### Format Rules
- Each question is numbered (1, 2, 3…)
- The stem is a complete question or a sentence containing a blank
- Four answer choices labeled **A**, **B**, **C**, **D**
- Exactly one correct answer
- No "all of the above" or "none of the above" options
- Distractors are plausible and reflect common misconceptions
- Questions should reference the source when applicable: "According to Source 1…" or "Based on the cartoon…"

### Source Reference Format
When a source is provided, the question header reads:
```
Use Source 1 to answer question 1.
```
Or for multiple sources:
```
Use Sources 1 and 2 to answer questions 3 and 4.
```

### Example MCQ

**Use Source 1 to answer question 1.**

**1.** The perspective illustrated in Source 1 most closely reflects which of the following ideological positions?

A. Classical liberalism, because it prioritizes state regulation over individual freedom
B. Modern liberalism, because it emphasizes social welfare programs to address inequality
C. Fascism, because it advocates for the suppression of political opposition
D. Communism, because it calls for the collective ownership of all means of production

*(Correct answer: B — Related Issue 1, Outcome 1.3)*
*(Bloom's Level: Apply/Analyze)*

---

### Example MCQ — Cross-Source Synthesis

**Use Sources 1 and 2 to answer question 5.**

**5.** Which statement best describes the relationship between the perspectives presented in Sources 1 and 2?

A. Both sources support the expansion of state power to protect individual rights
B. Source 1 advocates for collective identity while Source 2 defends individual freedoms
C. Both sources reject the principles of classical liberalism
D. Source 1 presents a nationalist perspective while Source 2 presents a globalist perspective

*(Correct answer: B — Related Issue 1, Outcomes 1.4 and 1.5)*
*(Bloom's Level: Analyze)*

## Part B: Written Response Questions

### Format Rules
- Each written response is labeled **Written Response 1**, **Written Response 2**, etc.
- A clear issue statement is provided (the question the student must address)
- The student is required to take a position and defend it
- The student must reference specific sources by letter/number
- Mark allocation is clearly stated: typically **10 marks** for a full written response

### Written Response Structure
1. **Issue** — States the question clearly
2. **Sources** — Lists which sources the student should draw from
3. **Instructions** — Directs the student to state and defend a position using evidence

### Example Written Response

**Written Response 1** (10 marks)

**Issue:** To what extent should the state limit individual freedoms in order to promote the collective good?

**Sources:** Use Sources A, B, and C to support your response.

**Instructions:** State a position on the issue presented above. Use evidence from the sources and your knowledge of social studies to support your position. Your response will be assessed on the quality of your argument and the use of relevant evidence.

*(PoS Outcomes: Related Issue 3, Outcomes 3.1, 3.2)*
*(Bloom's Level: Evaluate/Create)*

## General Formatting Conventions

### Question Set Header
```
Social Studies 30-1
Source-Based Question Set
Course: [Course Name]
Total Marks: [X]
```

### Source Labels
- Sources are labeled **Source A**, **Source B**, **Source C** (for source sets)
- Or **Source 1**, **Source 2** when numbered sequentially

### Mark Allocation per Question Type
- Multiple Choice: **1 mark** each
- Short Answer: **3–5 marks** each
- Written Response: **10 marks** each

### Bloom's Taxonomy Level Tagging
Each question should include a metadata tag for internal use:
- `(Bloom's Level: Remember/Understand)` — recall, identify, define
- `(Bloom's Level: Apply/Analyze)` — interpret, compare, explain, cause/effect
- `(Bloom's Level: Evaluate/Create)` — judge, argue, synthesize, construct

### PoS Outcome Citation
Each question should cite the relevant Program of Studies outcome:
- `(Related Issue 2, Outcome 2.3)`
